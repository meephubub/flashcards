# Revision Timeline Integration Plan

## Overview
Integrate a visual revision timeline feature into the flashcards app that displays upcoming study sessions, exam schedules, and card review deadlines in an interactive timeline format. This will provide users with a clear, chronological view of their study commitments and help them plan their revision more effectively.

## Current State Analysis

### Existing Features
1. **Spaced Repetition System (SRS)**: FSRS-based algorithm in `lib/spaced-repetition.ts`
2. **Exam Scheduling**: Full exam planning system with `exam-scheduler.ts` and `exam-data.ts`
3. **Task Management**: Homework/tasks system in `app/tasks/page.tsx`
4. **Study Statistics**: Stats page at `app/study/stats/page.tsx`
5. **Exam Plan Summary**: Component `components/exam-plan-summary.tsx`
6. **Schedule Exam Modal**: `components/schedule-exam-modal.tsx`

### Data Structures
- `ExamPlan`: Exam plans with dates, strategies, and caps
- `ExamPlanSession`: Individual study sessions with targets and focus
- `CardProgress`: SRS progress for each card
- `Homework`: General tasks with due dates

## Proposed Features

### 1. Interactive Revision Timeline Component
- Visual timeline showing days/weeks/months
- Display exam sessions, card reviews, and tasks
- Color-coded by type (exam, review, task)
- Hover details and quick actions

### 2. Timeline View Modes
- **Day View**: Hour-by-hour schedule
- **Week View**: 7-day overview
- **Month View**: Calendar-style monthly view
- **Exam View**: Focused view around exam dates

### 3. Integration Points
- **Study Stats Page**: Add timeline tab/section
- **Deck View**: Show timeline for specific deck
- **Tasks Page**: Enhanced with timeline visualization
- **Dashboard**: Quick timeline overview

### 4. Data Aggregation
- Combine exam sessions, card due dates, and tasks
- Calculate workload distribution
- Identify high-intensity periods
- Show preparation progress toward exams

## Technical Implementation Plan

### Phase 1: Core Timeline Component (lib/)
1. Create `lib/timeline.ts` - Timeline data aggregation utilities
   - Function to aggregate all scheduled items
   - Calculate workload per day
   - Identify conflicts/overlaps
   - Generate timeline events

2. Create `lib/timeline-types.ts` - Type definitions
   - `TimelineEvent` interface
   - `TimelineView` type
   - `EventCategory` enum

### Phase 2: UI Components (components/)
1. Create `components/revision-timeline.tsx`
   - Main timeline visualization
   - View mode switcher (day/week/month/exam)
   - Event rendering with color coding
   - Interactive tooltips

2. Create `components/timeline-event-card.tsx`
   - Individual event display
   - Quick actions (complete, edit, navigate)
   - Progress indicators

3. Create `components/timeline-minimap.tsx`
   - Overview minimap for navigation
   - Zoom controls
   - Date range selector

### Phase 3: Integration (app/)
1. Update `app/study/stats/page.tsx`
   - Add "Timeline" tab
   - Integrate revision timeline component
   - Show timeline alongside existing stats

2. Update `app/tasks/page.tsx`
   - Add timeline view toggle
   - Show tasks in timeline format

3. Update `app/deck/[id]/page.tsx`
   - Add timeline section for deck-specific view

### Phase 4: Enhanced Features
1. **Workload Forecasting**
   - Predict future workload based on SRS
   - Show busy periods
   - Suggest optimal study times

2. **Exam Countdown**
   - Days until exam indicator
   - Preparation progress
   - Risk assessment

3. **Conflict Detection**
   - Identify overloaded days
   - Suggest rescheduling
   - Balance workload

4. **Export/Share**
   - Export timeline as image/PDF
   - Share study plan
   - Calendar integration (ICS)

## Data Flow

```
User Data Sources:
- Exam Plans (exam_plans table)

↓

Timeline Aggregation (lib/timeline.ts):
- Fetch all scheduled items
- Normalize dates and times
- Categorize by type
- Calculate workload

↓

Timeline Component (components/revision-timeline.tsx):
- Render visual timeline
- Handle interactions
- Display tooltips
- Manage view state

↓

Integration Pages:
- Study Stats
- Tasks
- Deck View
```

## Performance Considerations

1. **Data Fetching**
   - Batch requests for timeline data
   - Cache aggregated results
   - Paginate for long timelines

2. **Rendering**
   - Virtual scrolling for long timelines
   - Lazy load event details
   - Optimize re-renders

3. **Calculations**
   - Memoize expensive calculations
   - Background processing for forecasts
   - Debounce user interactions

## Success Metrics
